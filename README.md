# Agenda 50/50 — Portal completo

Versión 2.0 construida a partir del documento oficial Acuerdo N° 001/2026 – Agenda 50/50.

## Ejecutar
npm install
npm run dev

## Contenido
- Home institucional.
- Monitor 50/50.
- 11 temáticas priorizadas según el documento.
- Detalle modal de cada temática.
- Ruta de implementación.
- Metodología para llegar al 50/50.
- Principios e instrumentos de implementación.
- Dimensión territorial.
- Centro documental.
- Buzón ciudadano.

## PDF
Copiar el archivo oficial "Acuerdo 001.2026 Agenda 50.50.pdf" a:
public/Acuerdo-001-2026-Agenda-50-50.pdf

La interfaz ya apunta a esa ruta.
